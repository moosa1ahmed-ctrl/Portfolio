Digits of e, Digital Logic Circuit CP220 Digital Electronics · Individual project View Project

What I built

Designed a 4-bit combinational circuit that maps inputs 0–10 to digits of e, with invalid inputs 11–15 forced to 0000. I derived the Boolean logic from a full truth table, simplified it with Karnaugh maps, and built the final gate-level circuit.

My contribution

Completed the project individually, including simulation and testing of all 16 input combinations.

Tools & concepts used

  • Truth tables
  • Karnaugh maps
  • Minimized Boolean (SOP) expressions
  • Maxima, used to algebraically verify each derived Boolean equation against the truth table before building anything
  • CircuitVerse, used to build the actual gate-level circuit and simulate it across all 16 input combinations, including proper handling of invalid states
