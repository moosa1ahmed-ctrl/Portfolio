ParkSense AI In Progress Personal project · Solo build Private repo, in development

Description

A solo, ongoing personal project: a B2B SaaS parking management platform aimed at real pain points, including operators losing revenue to inefficient spot usage and theft, drivers losing time finding a spot, and most "smart" parking systems failing exactly where they're needed most, in underground structures with poor connectivity. It started as much as a way to learn backend development from first principles as a genuine product concept.

Tools & concepts used

  • FastAPI, PostgreSQL, Docker, Python
  • In-memory CRUD endpoints, ahead of full database integration
  • Planned: a reinforcement-learning spot-assignment engine extending the Q-learning work below
  • Planned: a computer-vision ANPR pipeline, built offline-first for poor-connectivity environments
Smart Parking: Optimization vs. Reinforcement Learning CP468 Artificial Intelligence · Team of 4 View Project

Description

Built for CP468 Artificial Intelligence as part of a 4-person team. Modeled the urban parking assignment problem as both a graph search task and a Markov Decision Process, to directly compare deterministic optimization against adaptive reinforcement learning on the exact same problem.

Tools & concepts used

  • Python
  • Dijkstra's algorithm with hill climbing
  • From-scratch Q-learning agent
  • Simulations across 3 constraint scenarios (availability, walking-distance limits)
  • Evaluation on total cost, adaptability, and convergence
  • Co-authored an 8-page IEEE-format research paper with the team and presented findings to the class
